# Terraform Providers

## Objective

Learn how Terraform communicates with cloud platforms using Providers.

## Topics Covered

- Terraform Provider
- AWS Provider
- required_providers
- Provider Block
- AWS Region
- terraform init
- .terraform
- .terraform.lock.hcl

## Commands Practiced

```bash
terraform init
terraform validate
```

## Key Learnings

- Providers allow Terraform to communicate with cloud platforms.
- AWS Provider is downloaded from the Terraform Registry.
- `.terraform` stores downloaded provider plugins.
- `.terraform.lock.hcl` locks provider versions for consistent builds.
